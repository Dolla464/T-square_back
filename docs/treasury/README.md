# خزينة أدوية — Excel

## الملف

- **`pharma-treasury-egp.xlsx`** — نظام حركة خزينة (CMO + توزيع، EGP).
- **`build_pharma_treasury_workbook.py`** — إعادة توليد الملف بعد تعديل الهيكل.

```bash
python docs/treasury/build_pharma_treasury_workbook.py
```

## متطلبات

- **Microsoft Excel 365** (أو إصدار يدعم `FILTER`, `XLOOKUP`, `SORT`, `VSTACK`).

## البداية السريعة

1. راجع ورقة **README** داخل الملف.
2. عدّل **الإعدادات**، **الحسابات**، **الجهات**، **دليل_حسابات_مقابل** حسب شركتك.
3. سجّل الحركات في **حركات_يومية** — تأكد **`يسمح_بالاعتماد = نعم`** قبل **`حالة_الاعتماد = معتمد`**.
4. **تحويلات**: سطران لكل TRX (دائن من / مدين إلى).
5. **شيكات**: استلام → إيداع → تحصيل (انظر المثال في `TRX-00001`).
6. **دفter_الحركات_المعتمدة** و **`_دفter_مرtب`** و **تحليل_تدflowات_نقدية** للتقارير والأرصدة.
